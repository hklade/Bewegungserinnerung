Mockup Schnelleingabe · Optionen · Monatsauswertung · Referenzgerät Samsung Galaxy A36 (412 × 892 dp). Das Zahnrad-Symbol öffnet von jedem Screen aus die Optionsseite. In der Schnelleingabe ist alles oberhalb der gepunkteten Trennlinie ohne Scrollen sichtbar; der scrollbare Bereich beginnt direkt mit der Aktivitätsauswertung (jetzt inkl. stündlicher Balkengrafik), darunter folgt die letzte Aktivität. Die Optionsseite übernimmt alle bisherigen Einstellungen außer dem Exportpfad, zeigt das Trinkziel in ml (Standard 2000) und bietet 3 kurze Erinnerungstöne inkl. Testabspielen — „Aufwärts" ist der bereits bestehende Ton. Eine eigene Daten-Karte bietet Export/Import als CSV. Die Monatsauswertung zeigt Gesamtstatistik, eine Kalender-Heatmap pro Tag und den Wochentrend über den Monat.
